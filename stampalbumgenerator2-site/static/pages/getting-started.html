Getting Started

Back to home

Start with the binary for your platform, then launch the app and select your Albums Root folder.

  1. Download Linux or Windows build from the main page.
  2. Place the binary in a folder where album outputs can be created.
  3. Run once to generate initial config and menu/icon support files.
  4. Pick a country in Review UI and generate first pages.
