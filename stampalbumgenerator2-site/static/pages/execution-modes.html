Execution Modes (After Startup)

Back to docs index

After startup validation, the application routes into one of the main operating modes.

1. Review UI Mode

When `--review-ui` is active (or auto-enabled on no-arg interactive launch), the app enters startup selector flow and then compare/review flow.

  • Startup selector: `run_review_ui_bootstrap(...)`
  • Main review server/session: `run_review_ui(...)`

2. Database Mode

`run_database_mode(...)` handles output generation from an existing database path, and can also process Colnect import flows.

  • Opens/initializes target database
  • Optionally ingests Colnect CSV data
  • Runs album output generation from DB contents

3. Scraping Mode

`run_scraping_mode(...)` handles source scraping workflows (for example, StampWorld or US1847), then produces local output in canonical country storage.

  • Validates and resolves site and album naming
  • Builds collector/generator configuration
  • Executes scrape/import and output stages

Primary implementation references: `src/modes.rs`, `src/review_ui.rs`, and `src/validation.rs`.
