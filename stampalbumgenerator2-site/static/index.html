Preamble

How some simple scripts grew into Stamp Album Generator 2

This project started as a simple script meant to improve one small part of an AlbumEasy-based workflow. As often happens, a small utility turned into something much larger.

Over time, I tried a range of commercial and free album generators, prebuilt PDF sets, and other tools. Many of them had strong features and were likely excellent choices for other collectors. I simply wanted something different for the way I collect and organize albums.

At first, the process was mostly manual: copying, pasting, comparing, and refining details from many sources until the results matched what I wanted to see on the page. That eventually led me toward AlbumEasy, which already provided a large part of the flexibility I wanted to build on.

From there, the project became a question of improvement and automation. The result is an application that runs as a GUI on both Windows and Linux, while also supporting a full command-line workflow for generating stamp album pages.

Because the starting materials were often just images and text, a surprising amount of mathematics went into making the layout work well automatically. Spacing, scaling, alignment, and placement all had to be calculated so the pages would remain readable, balanced, and printable.

Of course, the project did not stop there. It grew to include country flags, coats of arms, Wikipedia integration as a work in progress, Colnect import support, StampWorld integration, and automatic configuration behavior at launch, along with a Windows version and continuing refinements.

This is still a work in progress, but it is already built around the features and workflow that matter most to me as a collector.

AlbumEasy foundation

AlbumEasy is core to this project

Stamp Album Generation startup: Pick a country to open its review UI.

This program could not be completed without the incredible AlbumEasy by Bundu Technology Ltd. It is a foundational part of how this workflow is designed, and it deserves significant credit.

Learn more about AlbumEasy and download it here: Bundu Technology Ltd. AlbumEasy.

We have implemented about 70-80% of AlbumEasy commands. You can edit the final output and add any additional commands that are not auto-generated.

📁 If you have not yet set up your Albums Root folder, you can do so now or let it auto-detect on launch. The Albums Root is where generated albums and related data are stored, and you can change it later in the config editor.

📬 If you have a Colnect inbox export and want to use it for review, you can import it now or later from the config editor. The default expected format is Colnect's "Export" option.

Integrated by design

Stamp Album Generator 2 is organized to keep collectors moving: install, configure, review, and generate albums with fewer steps and clearer controls.

Behind that smooth experience is a substantial amount of mathematics, from layout and spacing calculations to scaling and placement logic, all working together to produce consistent, printable album pages.

Current release focus

Right now we are publishing app binaries only, with Linux and Windows support first. You can download the latest version without reading all of the detailed instructions.

For download integrity, the recommended approach is signed SHA-256 verification, not CRC alone. See the download verification guide for the exact files and commands.

Published checksum files: stamp_album_gen2.sha256, stamp_album_gen2.exe.sha256, SHA256SUMS.txt, and CRC32SUMS.txt.

This is a single Rust binary. On first run, it creates the config files, icons, menu additions, and starter folders automatically.

Select a good location for the binary, because on startup it creates files and albums directly below that location. The application can be configured in many ways, but if you skip the documentation, your mileage may vary.
