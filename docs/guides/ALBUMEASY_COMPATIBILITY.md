# AlbumEasy Command Reference & Compatibility

## Overview
Cross-reference between generated commands and AlbumEasy_4.2.1.pdf manual to ensure compatibility and identify missing features.

## Windows Executable Path

In the Review UI config editor, enter the AlbumEasy executable path, for example
`C:\Program Files (x86)\AlbumEasy\AlbumEasy.exe`. Surrounding pasted double quotes
are also accepted; the editor escapes backslashes when saving TOML.
For manual TOML edits, use a literal string:

```toml
[runtime]
albumeasy_cli_path = 'C:\Program Files (x86)\AlbumEasy\AlbumEasy.exe'
```
