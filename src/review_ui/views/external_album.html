Import help, fidelity checks & editing limitations

Select the folder containing your AlbumEasy text file and images. Enter the text filename relative to that folder. The entire folder is copied into a new album under Albums Root, including unused images and supporting files. Existing destinations are never merged or overwritten. Do not select a parent folder. Recursion could happen!

The importer reconstructs supported commands as database layout records: page and row order, headings, stamp boxes, captions, margins, fonts and image settings. It does not infer catalogue numbers from filenames or physical stamp sizes from box dimensions. Repeated image placements are retained.

Unsupported commands, missing images, unsafe paths and incompatible files block conversion. A compatibility report records source lines and legacy commands for future support. Commands are not silently discarded. Initial command coverage is the Brazil example; this is not yet a complete AlbumEasy editor.

Configure AlbumEasy using the existing setup controls before importing. The app renders both the original command document and the database reconstruction in the copied folder. Compare the two fresh PDFs and approve fidelity before the album becomes ready. Successful rendering alone does not prove visual equivalence.

After approval, edit or insert stamps and text on a selected page. Saving reflows only that page; other pages keep their saved layout. If content does not fit, reduce it or adjust that page rather than allowing silent spillover. Global settings intentionally affect the whole album. Imported albums use this layout editor, not the StampWorld/Colnect matching screen.
